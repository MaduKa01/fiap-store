# Análise de vulnerabilidades

Pendente de execução de `bash scripts/06-scan.sh` nas imagens publicadas. Este arquivo não é um relatório de scan e não declara conformidade.

Para cada CRITICAL real, registre: imagem e digest; data do scan; CVE; pacote e versão; versão corrigida, se houver; impacto no contexto; correção aplicada ou justificativa específica e risco residual. Guarde os JSON e os resumos gerados nesta pasta. Sem CRITICAL, registre a conclusão somente após revisar os relatórios.
